# SOP-IT-003: Software Licensing and Access Request Standard

## Purpose
Guidelines for requesting, approving, and provisioning enterprise software licenses and developer tool access.

## Scope
Covers productivity tools, developer environments, cloud infrastructure accounts, and specialized design software.

## Tier Classification and Approval Matrix

### Tier 1: Standard Productivity Software
- Software: Microsoft 365 Enterprise, Slack, Zoom, Google Workspace, Notion.
- Approval: Pre-approved for all active employees. Automated provisioning within 1 hour of onboarding or request submission.

### Tier 2: Developer and Engineering Tools
- Software: JetBrains All Products Pack, Docker Desktop Pro, GitHub Enterprise Copilot, Postman Enterprise.
- Approval: Requires Direct Engineering Manager approval.
- SLA: 24 business hours.
- Request Process: Submit a ticket through the AI Helpdesk Assistant specifying project code and manager email.

### Tier 3: Cloud Infrastructure and Administrative Access
- Platforms: AWS Console, Google Cloud Platform (GCP) IAM, Production Kubernetes Clusters, Jira Admin.
- Approval: Requires Department Head and IT Security Officer dual-approval.
- Security Requirement: Mandatory hardware security key (FIDO2 / YubiKey) and completion of annual Security Awareness Training.
- SLA: 48 to 72 business hours.
